# Furniro

Responsive multi-page furniture e-commerce website based on the Furniro Figma community design.

## Pages

- Home
- Shop
- Product details
- Cart and checkout
- Product comparison
- Blog
- About
- Contact

## Run locally

Open `index.html` directly in a browser or start a local server:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Stack

HTML, CSS and vanilla JavaScript. All images and fonts are stored locally.
